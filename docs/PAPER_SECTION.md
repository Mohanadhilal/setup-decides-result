## Code and data availability

The implementation is publicly available at https://github.com/<FILL IN>/<FILL IN>. The commit that
produced the results reported here is tagged `paper-v1` (<FILL IN: 40-character SHA>); results should be
reproduced from that tag rather than from the default branch. The repository contains the diffuser model
and the Gymnasium environment, the three classical controllers in both their single-variable and
draft-loop forms, the Soft Actor-Critic, Twin Delayed Deep Deterministic Policy Gradient and Proximal
Policy Optimization implementations, the multi-seed training and checkpoint-selection code, the
evaluation protocol used by every experiment, the Pareto-front enumeration, the set-point sweep, the
gate-strictness sweep, the disturbance study, and the figure scripts. Configuration files carry every
setting listed in Table 2, including the three disjoint seed sets, the admissibility gate and the
preference vectors, and the raw per-seed outputs behind Tables 3 to 10 are committed as CSV files. The
selected checkpoint of each training run is recorded in a JSON file naming the checkpoint index, the gate
that admitted it and both seed lists, so that a reported number can be traced to a specific policy.
Trained weights are released as a versioned archive at <FILL IN: DOI or release URL>, which allows the
reported policies to be evaluated without retraining. The seven tooling errors described in Section 5.8
are documented individually in the repository, and the superseded runs affected by the training-signal
error are preserved alongside the corrected ones so that the artefact can be reproduced and compared.
Software versions are pinned; the full pipeline runs on CPU in approximately 30 to 40 core-hours.
